## 驼峰翻译助手

选中文字后翻译成英文，再转成变量名。已经是英文的内容会直接转换。

[有问题直接报 issue](https://github.com/han013/camel-translation/issues)

## 翻译

支持谷歌、谷歌中国、必应、百度、有道。百度和有道需要在设置里填写应用 ID 和密钥。

命令面板执行「驼峰翻译助手: 打开设置」，可以用可视化页面修改引擎、密钥和代理。

## 快捷键

```
选择翻译：Ctrl + .
驼峰(小)：Ctrl + ,
```

其余命名形式在命令面板里以「驼峰翻译助手」开头。

选中文字后右键，「翻译」会直接转成帕斯卡。「命名转换」是二级菜单，可改选驼峰、下划线等格式。

## 代理

翻译请求默认直连。需要出网时有两种方式：

- 手动地址：填写 `http://127.0.0.1:7890` 或 `socks5://127.0.0.1:7891`。本机 Clash、V2Ray 等客户端的本地端口用这种方式。
- 机场订阅：粘贴订阅链接后执行「同步机场代理」。扩展读取 Clash、Sing-box 或分享链接，在 HTTP / SOCKS 节点里按延迟自动选择，也可以从状态栏或「切换代理」里手动换。

vmess、vless、trojan、ss 等协议会显示在列表中，但不能直接拿来发请求。这类节点请在本地客户端里开启端口，再改用手动地址。

订阅链接和密钥保存在本机 VS Code 设置中。
